HTML Foundations

HTML provides the structure of a web page. It tells the browser what different pieces of content represent.

A well-structured document uses semantic elements so that browsers, search engines, and assistive technologies can understand the page.

<h1>My Web Page</h1>

Headings create a hierarchy for your content, while elements such as paragraphs, lists, and sections organize related information.

  • Use meaningful semantic elements.
  • Keep heading levels logically organized.
  • Give images useful alternative text.
<p>Welcome to my website.</p>
CSS Styling

CSS controls the visual presentation of HTML. It can change colors, spacing, typography, layouts, and animations.

Selectors determine which elements receive a particular style rule. Properties then define exactly how those elements should appear.

body { background: #f5f7fb; }

Classes are useful when you want to reuse a particular visual style across multiple elements.

  • Choose colors with sufficient contrast.
  • Use consistent spacing throughout a design.
  • Prefer reusable classes for repeated styles.
.card { padding: 20px; border-radius: 12px; }
JavaScript Basics

JavaScript adds behavior and interactivity to web pages. It can respond to user actions and update the document dynamically.

Variables allow programs to store information that can be used later. Modern JavaScript commonly uses const and let.

const message = "Hello, web!";

Functions group reusable instructions into a single operation. They can accept information and return a result.

  • Use descriptive variable names.
  • Keep functions focused on one task.
  • Use event listeners for user interactions.
function greet(name) { return `Hello, ${name}`; }
Responsive Design

Responsive design allows a website to adapt to different screen sizes. A layout that works on a desktop should also remain usable on phones.

Flexible units, responsive images, and media queries are common tools for creating adaptable interfaces.

@media (max-width: 700px) { ... }

Mobile-first design starts with a small screen and progressively adds enhancements for larger displays.

  • Test layouts at several screen widths.
  • Avoid unnecessary horizontal scrolling.
  • Make interactive controls easy to tap.
width: min(100%, 900px);
Development Workflow

A consistent workflow makes development easier to manage and debug. Breaking a large task into smaller pieces helps you identify problems.

Version control systems allow developers to track changes and safely experiment with new features.

git status

Before considering a project complete, test the interface, check the console for errors, and verify that the layout works across devices.

  • Plan the structure before writing complex code.
  • Test features as you build them.
  • Review accessibility and responsive behavior.
  • Keep your code readable and maintainable.
git add . git commit -m "Finish documentation page"
